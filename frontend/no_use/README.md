# frontend/no_use

Dart files the app does not use any more (nothing imports them, or only the hidden tabs did). Moved here in Part 20 (29 Nov 2026), NOT deleted.
This folder is outside `frontend/lib`, so the app build does not compile it. Paths inside keep the same shape as `lib/` (for example `no_use/widgets/ai_desk_card.dart`).
To bring a file back: move it to the same path under `frontend/lib/`. The list of the first 38 files is `tools/no_use_list.txt`.
